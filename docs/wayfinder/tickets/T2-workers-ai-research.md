# T2: Workers AI 中文模型能力调研

**类型**: research（AFK）
**状态**: open
**阻塞**: T10（AI prompt 设计）

## Question

Cloudflare Workers AI 当前可用的模型中，哪些支持中文文本分类/情感分析/摘要？效果如何？能否在单次推理中完成"判断是否为梁相关新闻→极性分类（正面/负面/中性）→影响力评估→生成简短摘要"的流水线？

### 需要调研的内容

1. Workers AI 当前可用的文本分类、情感分析、文本生成模型列表。
2. 中文支持质量——特别是中文科技梗（"梁圣"、"牢梁"、"跳票"等网络用语）的理解能力。
3. 推理延迟和 token 限制——Cron job 中批量处理 10-20 条新闻是否可行？
4. 是否有合适的模型可以直接做 zero-shot 分类（给定 rubric 判断极性和影响力）？
5. 如果没有现成的中文情感分析模型，是否可以用通用 LLM（如 Llama/Qwen 的中文版本）通过 prompt engineering 完成？
6. 免费额度和定价——玩票项目的成本考量。

### 输出

模型选型建议 + 简单的能力验证结果（用 3-5 条测试新闻验证准确率）+ 初步 prompt 骨架。
