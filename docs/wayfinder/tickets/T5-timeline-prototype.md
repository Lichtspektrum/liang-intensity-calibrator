# T5: 右侧时间线 UI 原型

**类型**: prototype（HITL）
**状态**: open
**阻塞**: 无（但 T11 API 契约依赖时间线的数据需求）

## Question

在现有界面右侧红框区域（竖长矩形，约屏宽 1/10，全高）设计纵向时间线。已确定的约束：

- 纵向时间轴（Q10=A），上面标记关键事件节点
- 关键事件来源于自动新闻采集（Q20 补充）
- 点击节点可以回看该日期的分值形态
- 事件在时间线上有大小区分（大事件大标记，小事件小标记）
- 风格与现有仪表盘美学一致

### 需要原型化的内容

1. 时间轴的视觉设计（线条、节点、事件预览）
2. 节点的视觉层级（什么算"大事件"？高影响力新闻？分值剧烈变化？还是 AI 标记的？）
3. 点击节点后的交互：滑杆跳到对应分值、人像变化到对应形态、是否显示事件摘要弹层
4. 回看模式的退出方式（自动回到实时？有返回按钮？再次点击当前节点？）
5. 事件过多时的处理（折叠？滚动？只显示最近 N 个？）
6. 移动端适配
