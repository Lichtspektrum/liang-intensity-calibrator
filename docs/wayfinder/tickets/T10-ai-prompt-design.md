# T10: Workers AI prompt 设计

**类型**: grilling（HITL）
**状态**: open
**依赖**: T1（新闻源调研）, T2（Workers AI 模型调研）
**阻塞**: T11（API 契约——不直接阻塞，但 prompt 输出格式影响 worker 内部实现）

## Question

基于 T2 选定的 Workers AI 模型，设计新闻分析的 prompt。AI 需要完成的任务：

1. **相关性判断**：这条新闻是否与梁文峰/DeepSeek/梁系浓度相关？（过滤掉不相关的科技新闻）
2. **极性分类**：这条新闻对梁系形象是正面（更接近梁神/梁祖）、负面（更接近小难梁/牢梁）、还是中性？输出 polarity ∈ [-1, 1]。
3. **影响力评估**：这是多大的事？输出 impact ∈ [0, 1]。
4. **事件摘要**：生成 1-2 句简短中文摘要，用于时间线标记展示。
5. **事件标签**：可选，如"版本发布"、"技术突破"、"产品事故"、"舆论争议"等，用于聚类和时间线图标。

### 需要考虑的

- 中文科技圈的梗和黑话（"梁圣"、"牢梁"、"跳票"、"开源"、"超越GPT"等）需要在 prompt 中提供 rubric 说明。
- 每条新闻分析的输入：标题 + 摘要/正文片段 + 来源。
- 输出格式：严格的 JSON，方便 worker 解析。
- 批量处理：一次 prompt 处理多条新闻，减少推理次数。
- 同日新闻合并后，是否需要 AI 重新生成合并摘要？

### 评分 rubric 参考（需要和用户校准）

- 极强正面（polarity > 0.7）：发布突破性模型/性能超越 SOTA/重大开源发布
- 正面（0.3 ~ 0.7）：正常版本更新/正面媒体报道/良好用户口碑
- 中性（-0.3 ~ 0.3）：常规公告/无关痛痒的新闻/行业评论
- 负面（-0.7 ~ -0.3）：产品事故/服务宕机/跳票/负面争议
- 极强负面（< -0.7）：重大安全事故/严重舆论危机/产品彻底失败
