# T6: 滑杆回弹交互原型

**类型**: prototype（HITL）
**状态**: open
**阻塞**: 无

## Question

用户拖动滑杆浏览各形态后，松手自动回弹到社区共识分值（Q6=A）。需要确定回弹的交互细节。

### 需要原型化的内容

1. **回弹触发时机**：松手即回弹？松手后停留 1-2 秒再回弹？在滑杆失去焦点时回弹？
2. **回弹动画**：线性？ease-out？弹性（spring）动画？回弹速度/持续时间？
3. **回弹过程中**：人像是否平滑插值变化（已经支持连续帧视频，应该可以）？
4. **回弹期间用户再次拖动**：是否打断回弹？
5. **回看历史模式（点击时间线节点后）**：此时滑杆锁定在历史分值，回弹行为是否不同？是否需要显式"回到实时"按钮？
6. **首次加载**：页面加载时滑杆是否需要从 0 动画到当前共识分值（仪式感），还是直接显示？
