# T9: 冷启动与投票主导的切换条件

**类型**: grilling（HITL）
**状态**: open
**依赖**: T3（打分算法精确公式）
**阻塞**: T11（API 契约）

## Question

上线初期投票不足，分值由新闻情感驱动初始偏移；投票量足够后投票成为唯一驱动，新闻仅做时间线标记。需要确定：

1. **冷启动期新闻如何影响分值**：
   - 冷启动阶段新闻的 polarity × impact 是否直接作为 Δscore 注入？
   - 冷启动阶段新闻的衰减速率和投票衰减一样（月半衰期）还是不同？
   - 冷启动阶段是否同时接受投票，两者如何混合？
2. **切换条件**：
   - 累计多少票后切换到投票主导？（比如累计 500 票？或前 7 天为冷启动期？）
   - 切换时新闻产生的历史分值怎么处理？直接清零到 50 让投票接管？平滑过渡？
3. **切换后新闻的角色**：
   - 新闻完全不影响分值，只在时间线上作为事件标记展示？
   - 还是新闻仍然作为"方向性信号"低权重参与投票（比如新闻偏正面时，Up 票的权重略增）？—— Q16 说"新闻主要用于冷启动"，倾向于前者。
4. **冷启动期间时间线是否有数据**：冷启动期的每日分值快照是否记录？
