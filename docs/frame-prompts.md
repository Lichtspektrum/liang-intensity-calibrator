# 31 帧生成清单

## 固定约束

每张中间帧使用区间左锚点、右锚点和上一张已生成帧作为参考。输出为 1254×1254 正方形写实棚拍照片。

必须保持：同一名成年中国男性、正脸、双眼水平、鼻尖居中、肩线水平、相同裁切、细框眼镜、无手势、无文字、无水印、无额外人物。每次只推进约六分之一的神情、骨相、服装和背景变化。
